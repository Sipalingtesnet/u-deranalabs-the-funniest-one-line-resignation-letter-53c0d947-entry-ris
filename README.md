**Line:** "8,412 retries for you, zero thank yous; I would have let it go, but I kept count, and I'm taking it with me."

A retry loop that has spent its whole life quietly re-running the same failed request files its notice, and the only asset it ever accumulated is the tally.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.

Set `MAKEFUN_OUTPUT_DIR` to write somewhere else. The program is deterministic and offline: same bytes every run, no trailing newline, 108 characters.
